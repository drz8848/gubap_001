# 东方财富网股吧爬虫

基于 Playwright 的东方财富网股吧帖子爬虫，支持自动提取股票论坛文章及详细信息并存入 SQLite 数据库。

## 功能特性

- 🕷️ 自动爬取股吧帖子列表及详情
- 📊 提取帖子正文、点赞数、评论数、作者信息
- 💾 本地 SQLite 数据库存储，无需云数据库
- 🔄 **支持断点续爬**：程序中断后可从上次停止位置继续爬取
- 🤖 智能识别验证码，支持人工介入
- 📦 模块化设计，易于扩展和维护

## 断点续爬原理

本项目的断点续爬通过三个层面实现：

### 1. 页面级断点（`crawl_page` 字段）
- `stock_crawl_task_log` 表记录每只股票已爬取的页数
- 程序启动时自动读取已爬页数，计算起始页码：`起始页码 = 总页数 - 已爬页数`
- 例如：总3345页，已爬2页 → 从第3343页开始继续爬取

### 2. 文章级去重（URL集合）
- 程序启动时预加载所有已爬文章的URL到内存集合
- 每页提取文章列表后，自动过滤已存在的URL
- 即使页面中有部分文章未爬（如中断），也只爬新文章

### 3. 动态更新进度
- 每爬完一页立即更新 `crawl_page` 字段
- 每爬完一篇文章立即将其URL加入内存集合

```
启动程序 → 加载已爬URL集合 → 读取已爬页数
    ↓
跳过已爬页面 → 过滤已爬文章 → 只爬新内容
    ↓
实时更新进度 → 中断后再次启动 → 自动继续
```

## 快速开始

### 1. 运行爬虫（断点续爬版本）

```bash
python 主程序.py
```

### 2. 运行旧版主程序

```bash
python 主程序_旧版.py
```

### 3. 控制爬取数量

编辑 `主程序.py` 开头的控制变量（第16-24行）：

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `控制变量1_限制` | 最多处理多少只股票 | 999999 |
| `控制变量2_限制` | 每只股票最多爬取多少页 | 999999 |
| `控制变量3_限制` | 每页最多爬取多少篇文章 | 999999 |

设置为 `0` 或移除相应的 `break` 条件可不限制爬取。

### 4. 可视化编辑器

```bash
python 可视化编辑器.py
```

（目前没有什么大用）

## 数据库结构

项目使用 SQLite 数据库 `pachong_001.db`，包含三张表：

| 表名 | 说明 | 关键字段 |
|------|------|----------|
| `stock_bar_base` | 股票基础信息 | `stock_code`, `guba_list_url`, `crawl_status` |
| `stock_crawl_task_log` | 爬取任务记录 | `stock_code`, `crawl_page`（已爬页数）, `crawl_status` |
| `stock_guba_post` | 股吧帖子数据 | `post_url`（唯一标识）, `post_content`, `like_num` |

**Q: 爬虫运行时遇到验证码怎么办？**

A: 程序会自动检测验证页面并暂停，等待您手动完成验证后在终端按回车继续。

**Q: 如何重置所有爬取任务？**

```python
设置任务状态并获取任务列表.重置所有爬取状态()
```

**Q: 程序中断后如何继续爬取？**

A: 直接再次运行 `python 主程序.py`，程序会自动读取已爬进度，从上次停止位置继续。

**Q: 爬虫支持哪些子域名？**

A: 目前支持：
- `guba.eastmoney.com`（股吧）
- `caifuhao.eastmoney.com`（财富号）

**Q: 如何查看已爬取的数据？**

A: 使用SQLite数据库工具打开 `pachong_001.db`，查询 `stock_guba_post` 表。
