# 东方财富网股吧爬虫

基于 Playwright 的东方财富网股吧帖子爬虫，支持自动提取股票论坛文章及详细信息并存入 SQLite 数据库。

## 功能特性

- 🕷️ 自动爬取股吧帖子列表及详情
- 📊 提取帖子正文、点赞数、评论数、作者信息
- 💾 本地 SQLite 数据库存储，无需云数据库
- 🤖 智能识别验证码，支持人工介入
- 🎯 支持断点续爬，自动记录爬取进度
- 📦 模块化设计，易于扩展和维护

## 环境要求

- Python 3.8+
- Chrome/Chromium 浏览器（用于 Playwright）

## 安装依赖

```bash
pip install playwright pandas sqlite3 ttkbootstrap
playwright install chromium
```

## 快速开始

### 1. 运行爬虫

```bash
python 主程序.py
```

### 2. 控制爬取数量

编辑 `主程序.py` 开头的控制变量（第16-20行）：

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `控制变量1_限制` | 最多处理多少只股票 | 2 |
| `控制变量2_限制` | 每只股票最多爬取多少页 | 2 |
| `控制变量3_限制` | 每页最多爬取多少篇文章 | 2 |

设置为更大数值或移除循环中的`break`条件可进行完整爬取。

### 3. 可视化编辑器

```bash
python 可视化编辑器.py
```

（目前没有什么大用）

## 数据库结构

项目使用 SQLite 数据库 `pachong_001.db`，包含三张表：

| 表名 | 说明 |
|------|------|
| `stock_bar_base` | 股票基础信息（股票代码、股吧链接、爬取状态） |
| `stock_crawl_task_log` | 爬取任务记录（任务名称、已爬页数、状态） |
| `stock_guba_post` | 股吧帖子数据（标题、正文、点赞、评论、作者等） |
